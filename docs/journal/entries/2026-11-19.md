# 2026-11-19: Phase 2, the web app (local)

## Goal

Rebuild BlinkGuard as a browser app that keeps all processing on the user's device, in English with a French switch, without deploying it yet.

## Done

- **New [`web/`](../../../web/) app** (`cc9c9f3`, branch `feat/web-app`) with Vite and TypeScript, no UI framework:
  - Eye tracking with **MediaPipe Face Landmarker** (WebAssembly, GPU with a CPU fallback). The runtime and model are copied into the app by `scripts/fetch-assets.mjs`, so it never calls another server.
  - The **alert rules** of desktop v1 ported to `src/core/` as pure TypeScript, together with their tests.
  - The **alarm** is synthesised with the Web Audio API (no audio files), plus a flashing banner so it works without sound.
  - **PDF reader** with pdf.js: open or drag and drop, pages, zoom.
  - **Session statistics** with CSV/JSON export.
  - **English and French**: language detected from the browser, switch in the top bar, a test that checks both languages have the same keys and placeholders.
  - A **privacy notice** before the camera starts. It also says the app is not a medical device.
  - A strict **Content-Security-Policy** on production builds. PDFs are treated as untrusted input.
- **Tests:** 31 Vitest tests. **CI:** a new web job (typecheck, tests, build) next to the desktop job, both green.
- **Checked in the browser:**
  - The production build loads with no errors under the CSP, and the face model starts on the GPU.
  - The language switch, PDF loading, pages and zoom work, and stats count pages.
  - The privacy dialog shows, and a refused camera gives a clear message.
- **Journal started**: this folder, the [decision log](../decisions.md) and the [changelog](../../../CHANGELOG.md).

## Learned / problems

- The embedded test browser blocks webcams, so live eye tracking has to be tested in a normal browser.
- A browser that is not drawing (a hidden window) pauses `requestAnimationFrame`. pdf.js rendering and the tracking loop wait for it. The app also clears its timers when the tab becomes visible again, so it never raises an alarm for time it could not observe.
- Browsers keep audio blocked until a user gesture. The audio context is unlocked on the Start click, and a warning appears if sound is still blocked.
- The "attention score" from desktop v1 was left out of the web version: scoring a person's attention is sensitive wording under the EU AI Act.
