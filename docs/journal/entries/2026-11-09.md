# 2026-11-09: Published on GitHub, review and core fixes

## Goal

Put the project on GitHub, then review it end to end (usefulness, regulation for going online, security, correctness, performance, code quality, tests, UX) before upgrading it.

## Done

- **Public repository** [GilDark012/BlinkGuard](https://github.com/GilDark012/BlinkGuard) (`76d4751`). Zips, the slide deck and the PDF stay local through `.gitignore`.
- **Full review.** The main findings:
  - The alarm logic counted frames instead of seconds, so the delay changed with the webcam speed.
  - A short eye opening could skip the cooldown.
  - Blinks were miscounted.
  - Nothing happened when the face left the camera (head dropping).
  - The sound played on a blocking thread, the UI froze on webcam errors, and the exports had no error handling.
  - The Streamlit version cannot work online.
  - There were no tests.
- **Fixes in the PyQt6 app** (`a7e612c`):
  - All timing in seconds with an injectable clock. A new "face lost" alert after 5 s.
  - Non-blocking sound.
  - Clear dialogs for webcam, model and PDF errors.
  - Debounced zoom and keyboard shortcuts.
  - Statistics fixed: real eye state, the CSV header is always written.
- **First test suite:** 33 pytest tests (alert state machine, eye state, PDF reader, statistics) using a fake clock, so no webcam is needed.

## Learned / problems

- MediaPipe 0.10.x breaks with `protobuf` ≥ 5. Pinning `protobuf<5` and using a dedicated virtual environment fixed it.
- MediaPipe cannot load its model files from a path with accents (`Année`). The virtual environment must live in an ASCII-only path. This is now in the README.
- `import fitz` is deprecated. Switched to `import pymupdf as fitz`.
