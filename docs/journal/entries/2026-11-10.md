## Learned / problems

- GitHub only plays a video inside a README when it is uploaded through the web editor, and free accounts are limited to 10 MB. GIFs play everywhere with no limit, so they were the better fit.
- To make a GIF small, generate a palette per clip (`palettegen` / `paletteuse`) and crop to the part of the window that matters.
